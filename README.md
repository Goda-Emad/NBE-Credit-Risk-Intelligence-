# 🏦 NBE Credit Risk Intelligence Platform

AI-powered credit risk assessment system for the National Bank of Egypt.

## 📊 Quick Stats
- **Accuracy:** 76.5%
- **Features:** 73 engineered features
- **Dataset:** 1,000 German credit applications
- **False Negatives:** 31 cases

## 🚀 Quick Start
```bash
# Install dependencies
pip install -r requirements.txt

# Run Streamlit app
streamlit run streamlit_app/app.py
```
